# Nafisat Ozohu Abdulsalam — Portfolio

A white-and-maroon academic portfolio made with HTML, CSS, and a small amount of JavaScript. No Node.js, npm, framework, API key, or build step is required.

## Open in VS Code

1. Extract this ZIP first.
2. In VS Code choose **File → Open Folder** and open the extracted `nafisat-portfolio` folder.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Edit the files, save, and refresh your browser.

## Where to edit

| File | What to change |
| --- | --- |
| `index.html` | About text, research interests, news, publications, education |
| `experience.html` | Research/work experience, leadership, awards, certifications, memberships |
| `projects.html` | Project descriptions and optional repository links |
| `gallery.html` | Photo filenames, captions, categories, and dates |
| `cv.html` | Editable CV and browser Print / Save as PDF button |
| `assets/style.css` | Colours, spacing, typography, responsive layout, news height |
| `assets/script.js` | Your LinkedIn/GitHub URLs, automatic photo loading, gallery lightbox |
| `assets/Nafisat-Abdulsalam-CV.pdf` | Downloadable CV; replace this when you update it |

Each HTML page is complete and editable. The profile/navigation is deliberately repeated in the four pages so it still appears without JavaScript. Update the profile in all four pages when you change it. Main content is written directly in HTML rather than generated by JavaScript.

To add another photo, copy a whole `<figure>...</figure>` block and edit the path, alt text and caption. Without JavaScript, the labelled empty states remain; all other content/navigation works.

## How the independent scrolling works

Desktop: `.layout` fills the viewport. `.reading-pane` scrolls on the right; the profile stays in the left column. A short screen or high zoom can scroll the profile separately so its contents remain reachable.

The news box has its own `overflow-y: auto` and height. Change `--news-height: 260px` at the top of `assets/style.css`. `overscroll-behavior-y: contain` keeps news scrolling from carrying over to the main panel. Keyboard users can tab to the box and use arrow keys.

Mobile: the profile appears above the page and the whole page scrolls naturally. The news box still scrolls independently.

## Update the CV

The included PDF was prepared from the details you supplied. The View CV button opens the editable `cv.html`; Download CV downloads the PDF.

1. Edit `cv.html`.
2. Open it in your browser and click **Print / Save as PDF**.
3. Select A4, disable browser headers/footers, and save the PDF as `Nafisat-Abdulsalam-CV.pdf`.
4. Replace `assets/Nafisat-Abdulsalam-CV.pdf` with that file.
5. Keep the corresponding Experience and About content in sync.

The HTML and PDF do not synchronise automatically.

## Publish on GitHub Pages

1. Create or open your intended GitHub repository. For a personal homepage, its name normally follows `YOUR-USERNAME.github.io`.
2. Put the **contents** of this extracted folder in the repository root: `index.html` should be at the top level, alongside `experience.html`, `projects.html`, `gallery.html`, `cv.html` and `assets/`.
3. Commit and push the files using VS Code Source Control or your normal Git workflow. Review existing files before replacing them; don't delete unrelated repository content.
4. In the repository's Pages settings, select deployment from your branch and the root folder. Follow GitHub's current interface if the labels differ.
5. Visit the address GitHub provides after deployment completes.

All internal URLs are relative, so the portfolio can also live under a project-repository URL. The `.nojekyll` file tells GitHub Pages to serve it as a plain static website. No hosted site has been published on your behalf.
